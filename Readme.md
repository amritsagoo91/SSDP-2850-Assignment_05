cd into project folder then run :
` npm install `

if it doesn't work then delete package.json file then

cd into project folder then run :

`npm install vite`
`npm install sass-embedded --save-dev`
`npm install tailwindcss`
`npm install @tailwindcss/vite --save-dev` 

To start the development server:

cd into Project folder and run:
`npm run dev`

Vite will start a local server (usually at http://localhost:5173)
